Copia exames e preços (sem e com contraste) da tabela origem para o destino. Por padrão, inclui somente os serviços que ainda não existem no destino, sem alterar os preços já cadastrados lá.

Escolha origem e destino nos combos (o sistema grava pelo id numérico do cabeçalho, visível na lista de Cabeçalhos — ex. JARDEL id 7, ABDES id 6). A origem precisa mostrar quantidade > 0 no combo. Atalho na URL: ?origem_id=7&destino_id=6. Shell (só faltantes): python manage.py replicar_tabela_preco --origem-id 7 --destino-id 6. Para atualizar os que já existem: acrescente --atualizar-existentes.
